FMOConsole 隐私政策

更新日期：2026 年 8 月 25 日

FMOConsole 尊重用户隐私。本政策说明 FMOConsole 在 iOS 设备上的数据处理方式。

我们处理的数据

为了提供消息中心、推送通知和 FMO Radio 控制功能，应用会处理下列数据：

数据用途处理位置
应用安装标识、安装鉴权凭据识别同一应用安装、保护消息接口并同步消息状态设备钥匙串及开发者消息服务
APNs device token、推送注册标识向已授权通知的设备发送消息开发者消息服务、Apple Push Notification service 和 Firebase Cloud Messaging
通知授权状态、消息已读状态和通知交互展示授权引导、同步未读数量并改进消息功能设备、开发者消息服务；部分通知交互可能由 Firebase Analytics 处理
应用语言、时区、应用版本/构建号、平台、Bundle ID 和推送环境选择消息语言、安排发送时间、兼容不同版本并排查推送问题开发者消息服务；Firebase Cloud Messaging 也会为推送功能处理其中部分设备和应用信息
第三方 SDK 技术诊断数据维持推送和安装服务、排查传输问题并衡量服务可靠性Firebase Messaging、Firebase Installations、Google Data Transport 等相关服务；此类诊断数据不与用户身份关联

应用和上述服务在建立网络连接时还会处理 IP 地址等必要的网络连接信息。FMOConsole 不接入广告 SDK，不出售数据，也不会将这些数据用于跨 App 或跨网站跟踪。

本地保存的数据

应用可能在设备本地保存用户输入的 FMO 设备地址和别名、收藏电台、最近连接记录、通联日志、消息缓存、语言及显示偏好。这些数据用于再次连接、离线浏览和恢复用户设置。除上文明确说明的消息服务和第三方服务字段外，本地数据不会上传到开发者消息服务。

用户选择的 FMO 网络连接

用户主动连接 FMO Radio 设备或服务器时，应用会向用户填写或选择的地址建立 WebSocket/网络连接，用于获取电台列表、当前通联状态、实时音频和设备公告等信息。这些通信发生在用户选择的设备或服务之间。

第三方服务

应用使用 Apple Push Notification service 发送系统通知，并使用 Google Firebase Cloud Messaging 管理推送注册。应用也集成 Firebase Analytics，用于处理 Firebase Messaging 产生的通知交互并了解消息功能的使用情况。第三方会按照其条款和隐私政策处理数据：

  • Apple 隐私政策
  • Google Firebase 隐私与安全说明

本地网络权限

应用请求本地网络权限，用于发现并连接局域网内的 FMO Radio 设备。

音频播放

应用使用音频播放能力来播放 FMO Radio 实时音频流，并支持后台播放。应用不会录音，也不会上传麦克风音频。

位置相关信息

应用不会请求设备定位权限。应用可能根据 FMO/APRS 数据中的网格或坐标显示距离、方位或地区信息；这些坐标并非来自用户设备定位。为显示地区名称，iOS 系统地理编码服务可能处理用于查询的坐标。

数据保留、删除与用户选择

设备本地数据通常保留到用户在应用中移除相关记录或卸载应用。消息服务数据仅在提供消息、推送、安全防护和故障排查所需期间保存；法律另有要求的除外。

  • 用户可以拒绝通知权限，或随时在 iOS“设置”中关闭 FMOConsole 通知。关闭后，应用会通知消息服务停用当前推送注册。
  • 用户可以在应用内删除最近设备、别名、收藏等可管理数据；卸载应用会删除应用容器中的本地数据。
  • 如需查询或删除开发者消息服务中的安装记录和消息状态，请通过下方联系方式提交请求。我们可能需要必要信息来确认目标安装，并会在适用法律要求的范围内处理。

数据安全

开发者消息服务使用 HTTPS 传输，并使用安装鉴权凭据保护安装级接口。用户自行填写的 FMO Radio 地址可能使用局域网连接或未加密的 ws://；对公网服务建议使用 wss://。

政策更新

如果应用功能或数据处理方式发生变化，我们会更新本页面并修改上方日期。重大变化会通过适当方式提示用户。
